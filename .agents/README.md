# Configuración de agentes

Esta carpeta contiene configuración para agentes de programación, no agentes o integraciones del producto. El [`AGENTS.md`](../AGENTS.md) raíz define el flujo común y exige consultar las instrucciones relevantes antes de editar.

- [`rules/`](./rules/README.md): convenciones y restricciones que aplican al trabajo del agente.
- [`skills/`](./skills/README.md): tareas reutilizables con entradas, procedimiento y criterios de aceptación verificables.

Las carpetas `/agents` y `/skills` de la raíz son áreas de producto distintas. Las reglas locales del componente, incluidos los `AGENTS.md` anidados, también aplican.

Reglas actuales: [`project-conventions.md`](./rules/project-conventions.md) y [`healthcare-data.md`](./rules/healthcare-data.md). Skill de flujo disponible: [`frontend-preflight`](./skills/frontend-preflight/SKILL.md).
