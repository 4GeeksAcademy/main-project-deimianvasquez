# Skills de agentes de programación

Esta carpeta contiene skills reutilizables para el agente de desarrollo. Cada skill vive en su propia subcarpeta con un `SKILL.md`; puede incluir scripts cuando aporten comprobaciones reproducibles.

Cada skill debe definir cuándo se usa, entradas, procedimiento, salida esperada y criterios de aceptación con evidencia verificable. Estas skills son configuración del agente de programación y no son las skills de producto de [`/skills`](../../skills/README.md).
